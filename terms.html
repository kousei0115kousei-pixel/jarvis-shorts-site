利用規約

制定日: 2026年10月23日

本規約は、「JARVIS Shorts」（以下「本ツール」）の利用条件を定めるものです。

1. 本ツールについて

本ツールは、運営者が自分のYouTubeチャンネルに雑学のショート動画を作成・投稿するために使う個人用ツールです。一般の方への提供・販売は行っていません。

2. YouTube 利用規約への同意

本ツールは YouTube API サービスを使用しています。本ツールを利用する者は、YouTube 利用規約に同意したものとみなします。Googleアカウントのデータの扱いはプライバシーポリシーおよびGoogle プライバシー ポリシーに従います。

3. 投稿するコンテンツ

  • 本ツールで作成する動画の台本と音声は、AIを使って生成します。投稿時にはYouTubeの「改変または合成されたコンテンツ」の開示設定を有効にし、説明欄にもAI生成であることを記載します
  • 台本は投稿前にAIによる事実確認を行い、確認に通らない内容は投稿しません
  • 他者の動画や著作物を複製・再投稿することはありません。YouTube コミュニティ ガイドラインおよびスパムに関するポリシーに従います
  • 投稿頻度は1日1本までとします

4. 禁止事項

  • 運営者以外のGoogleアカウントやYouTubeチャンネルへのアクセス
  • YouTube の利用規約、コミュニティ ガイドライン、YouTube API サービス利用規約およびデベロッパー ポリシーに反する利用

5. 免責

本ツールは現状のまま提供され、動作や生成内容の正確性を保証するものではありません。

6. 改定

本規約を変更する場合は、このページを更新し、制定日を改めます。
