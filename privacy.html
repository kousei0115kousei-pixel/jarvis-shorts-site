プライバシーポリシー

制定日: 2026年10月23日

「JARVIS Shorts」（以下「本ツール」）は、運営者が自分のYouTubeチャンネルの運用のためだけに使う個人用ツールです。本ポリシーでは、本ツールがGoogleアカウントのデータをどのように扱うかを説明します。

1. アクセスするデータ

本ツールは、運営者本人の許可を得たうえで、Googleの次の権限を使います。

  • YouTubeへの動画のアップロード（youtube.upload）: 作成したショート動画を運営者のチャンネルに投稿するため
  • YouTubeアカウントの閲覧（youtube.readonly）: 運営者のチャンネルの動画の再生数などを確認し、公開されている動画を検索するため
  • YouTubeアナリティクスの閲覧（yt-analytics.readonly）: 運営者のチャンネルの視聴維持率などを分析するため

2. データの使い方

取得したデータは、運営者のチャンネルへの投稿と、次に作る動画のテーマ・タイトルの改善にだけ使います。広告、データの販売、第三者への提供、AIモデルの学習には使いません。

3. 保存と共有

  • ログイン情報（OAuthトークン）は、運営者のコンピューターと、運営者のGitHubアカウントの暗号化された保管庫（GitHub Actions Secrets）にのみ保存します
  • 分析結果（再生数などの集計）は、運営者だけが閲覧できる非公開の場所に保存します
  • 動画の台本やテーマを作るために、公開情報（テーマ名・公開動画のタイトルや再生数）を外部のAIサービス（Groq、Google Gemini）に送信することがあります。Googleアカウントのログイン情報は送信しません

4. Google API サービスのユーザーデータに関するポリシー

本ツールによるGoogle APIから受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。本ツールはYouTube APIサービスを使用しており、利用者はYouTube利用規約に同意するものとします。Googleのプライバシーポリシーはこちらです。

5. アクセスの取り消し

本ツールへのアクセス許可は、Googleアカウントのセキュリティ設定（サードパーティ製のアプリとサービス）からいつでも取り消せます。取り消すと、保存されているログイン情報は使えなくなります。

6. 改定

本ポリシーを変更する場合は、このページを更新し、制定日を改めます。
