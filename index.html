JARVIS Shorts

運営者が自分のYouTubeチャンネル「雑学チャンネル」のために使う、個人用のショート動画作成・投稿ツールです。

このツールがすること

  • 日常で役立つ雑学をテーマに、台本・音声・字幕付きの縦型ショート動画を作成します
  • 作成した動画を、運営者自身のYouTubeチャンネルに投稿します
  • 運営者のチャンネルの視聴データと、公開されている動画の情報をもとに、次の動画のテーマを改善します

利用者について

このツールは運営者本人だけが使うもので、一般には提供していません。ほかの方のGoogleアカウントやYouTubeチャンネルにはアクセスしません。

YouTube API サービスの利用

本ツールは YouTube API サービス（YouTube Data API v3、YouTube Analytics API）を使用しています。利用者は YouTube 利用規約に同意したものとみなされ、Google によるデータの扱いは Google プライバシー ポリシーに従います。

プライバシーと利用規約

Googleアカウントのデータの扱いはプライバシーポリシー、利用条件は利用規約をご覧ください。
